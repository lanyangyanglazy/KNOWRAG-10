## 1. 现状基线

| 维度 | 现状 | 结论 |
|---|---|---|
| 部署 | 单机 CLI，Ollama 本地推理（qwen3:4b / bge-m3） | 可私有化，但无服务化 |
| 知识库 | 单个 `knowledge_base.txt`，20 个切片 | 无密级、无部门、无版本 |

| 权限 | 无 | **不可用于真实政务数据** |
| 审计 | 无 | **不满足等保审计要求** |
| 评测 | 46 个单元测试（代码正确性） | 无 RAG 效果评测集 |
| 运维 | 无监控、无限流、无备份 | 不具备生产可用性 |

## 2. 差距与优先级

优先级定义：**P0** = 不满足则不能承载真实政务数据；**P1** = 影响可用性与效果；**P2** = 长期演进。

| 层 | 差距 | 关键设计 | 优先级 |
|---|---|---|---|
| 合规安全 | 无等保/密评设计，无日志留存 | 等保 2.0 三级对标、商用密码应用、日志留存 ≥ 6 个月（网络安全法第 21 条）、生成式 AI 内容安全审核 | P0 |
| 身份权限 | 无登录、无文档级权限 | 对接统一身份（OIDC/LDAP/CAS）；RBAC + 文档级 ACL；**检索前裁剪候选集** | P0 |
| 密级治理 | 单一语料，无密级 | 密级标签（公开/内部/秘密）贯穿入库、检索、输出；不同密级分库存储 | P0 |
| 审计追溯 | 无 | 记录 用户/时间/问题/改写后查询/命中片段（含密级）/模型与提示词版本/输出全文 | P0 |
| 引用溯源 | 仅文件名 | 引用到 `doc_id + 切片 + 生效版本`，支持回源原文 | P0 |
| 拒答 | 仅 Prompt 约束 | 无可见文档直接拒答；相关性阈值 + 答案与片段一致性校验 | P0 |
| 内容安全 | 无 | 输入输出双向过滤（敏感词、涉密信息、个人信息）；防文档投毒与间接提示注入 | P1 |
| 检索效果 | 无 Rerank、无阈值 | bge-reranker 精排；召回率/引用准确率评测集与回归门禁 | P1 |
| 服务化 | 单进程 CLI | FastAPI + 队列 + 限流 + 超时降级；索引热更新 | P1 |
| 可观测 | 无 | 检索→重排→生成链路追踪；质量、时延、成本指标与告警 | P1 |
| 信创适配 | x86 + NVIDIA | 麒麟/统信、鲲鹏/飞腾、达梦/金仓、昇腾 NPU 全栈验证 | P2 |
| 多租户 | 无 | 部门级数据隔离、导出审批、水印 | P2 |

## 3. 目标架构

```
┌─────────────────────────────────────────────────────────────┐
│ 接入层   政务内网门户 / 统一身份网关(SSO) / 终端              │
├─────────────────────────────────────────────────────────────┤
│ 应用层   会话管理 · 问题改写 · 编排 · 限流 · 流式响应         │
├─────────────────────────────────────────────────────────────┤
│ 权限层   ★ 文档级 ACL · 密级校验 · 检索前候选集裁剪           │
├─────────────────────────────────────────────────────────────┤
│ 检索层   向量检索(FAISS/国产向量库) + BM25 → RRF → Rerank    │
├─────────────────────────────────────────────────────────────┤
│ 生成层   私有化 LLM · 引用标注 · 拒答判定 · 流式输出          │
├─────────────────────────────────────────────────────────────┤
│ 安全层   输入过滤 · 输出过滤 · 涉密检测 · 水印/溯源           │
├─────────────────────────────────────────────────────────────┤
│ 数据层   文档库(含密级/版本) · 向量库 · 审计库 · 评测集       │
├─────────────────────────────────────────────────────────────┤
│ 运维层   监控告警 · 链路追踪 · 备份恢复 · 灰度与回滚          │
└─────────────────────────────────────────────────────────────┘
```

关键约束：**权限层必须位于检索层之前**。先检索再删结果，片段可能已进入模型上下文，等于泄露。

## 4. 关键设计决策

### 4.1 权限前置过滤

- 每个切片带 `dept + classification_level + doc_id` 元数据
- 用户可见集合 = `level ≤ 用户密级` 且（`level = 公开` 或 `dept = 用户部门`）
- FAISS 检索传 `filter` 回调，只允许可见 `chunk_id` 进入候选；BM25 语料同样先裁剪
- 权限变更后索引无需重建（元数据不变），但变更需审计留痕

### 4.2 密级分库与最小权限

- 公开、内部、秘密分索引存储，避免一次查询跨密级
- 默认最小权限：新用户只有公开级；提权走审批流
- 导出、复制、打印按密级二次鉴权，前端加水印

### 4.3 引用回源

- 回答附带 `doc_id`、文档标题、部门、密级、切片序号、原文片段
- 保留文档生效版本快照，避免"引用的是旧版制度"
- 前端点击可定位原文，审计记录引用 id

### 4.4 拒答策略

1. 可见集合为空 → 直接拒答，不调用 LLM
2. 检索最高相关性低于阈值 → 拒答并提示换问法
3. 答案与引用片段做一致性校验（NLI/规则），不一致则降级为"仅返回原文片段"
4. 输出含敏感信息 → 拦截并告警

### 4.5 评测门禁

- 评测集：≥ 200 条（问题、标准答案、应命中 doc_id、应拒答标记）
- 指标：Recall@5、引用准确率、拒答准确率、平均时延
- 每次更换模型/提示词/切分参数必须跑回归，指标下降超 3% 阻断发布

### 4.6 信创与私有化

- 模型、依赖、向量库全离线镜像；禁止运行时外联
- 优先验证：麒麟 V10 + 鲲鹏 920 + 达梦 8 + 昇腾 910B
- 在线模型（当前支持的 DeepSeek）在政务场景默认关闭，需专项审批

## 5. 分期路线

### P0 试点（可承载内部非密/内部数据）

| 交付物 | 验收标准 |
|---|---|
| 统一身份 + 文档级 ACL | 越权提问拿不到任何片段，且审计可见 |
| 密级标签与分库 | 秘密文档不出现在内部用户检索结果 |
| 审计日志 | 每次问答可还原：用户、问题、片段、模型版本、输出 |
| 引用回源 | 答案中每条引用可定位到原文 |
| 拒答 | 无依据时不生成答案 |
| 部署基线 | 内网离线部署，无外联请求 |

### P1 可用性（可试点推广）

Rerank、评测集与回归门禁、内容安全过滤、服务化与限流、监控告警、索引热更新。

### P2 规模化（多部门推广）

信创全栈适配、多租户与导出审批、水印溯源、灰度与回滚、容量规划。

## 6. 本期已实现的试点原型

代码位置：`app/`（FastAPI + 单页前端），复用 `main.py` 的检索与生成组件。
运行方式、演示脚本、阈值校准与实测记录见 [`app/README.md`](../app/README.md)。

| 能力 | 实现 |
|---|---|
| 登录（演示） | 选择演示用户，签名 Cookie 会话（真实系统替换为 SSO） |
| 文档级 ACL | `can_view()` + FAISS `filter` + BM25 语料裁剪，**检索前**生效 |
| 密级标签 | 演示语料 `data/gov_docs/` 四个文档：公开/内部/秘密 |
| 混合检索 | 复用 FAISS + BM25 + RRF |
| 多轮与流式 | 复用 `condense_question` 与 `strip_think_stream` |
| 引用来源 | SSE `citations` 事件返回标题/部门/密级/片段 |
| 拒答 | 可见集合为空时直接返回"无依据" |
| 审计 | `logs/audit.jsonl`，每次问答一行 JSON |

**明确不包含**：真实 SSO、密评、内容安全过滤、Rerank、评测集、多副本。原型的价值是验证权限与审计的正确位置，不作为生产系统。

## 7. 验收清单（P0）

- [ ] 越权场景：不同部门用户问同一问题，结果集合严格不同
- [ ] 秘密文档在审计中可追踪，但不出现在无权用户响应中
- [ ] 审计日志字段完整、可导出、留存策略已配置
- [ ] 拒答场景不调用生成模型（节省算力且避免幻觉）
- [ ] 引用可回源到原文段落
- [ ] 离线环境冷启动成功，无外联
- [ ] 等保测评项自查表完成（身份鉴别/访问控制/安全审计/数据完整性）

## 8. 风险与遗留

| 风险 | 影响 | 应对 |
|---|---|---|
| 秘级标注依赖人工 | 标错即泄露 | 双人复核 + 抽检 + 自动化密级识别辅助 |
| 本地 4B 模型能力有限 | 复杂制度问答质量不足 | 场景限定 + Rerank + 拒答；必要时申请更大模型 |
| 权限与索引不同步 | 撤权后仍可检索 | 权限实时查询，索引只存元数据；撤权立即生效 |
| 日志含敏感内容 | 审计库本身成为风险 | 审计库独立加密存储、访问审批、脱敏字段 |
| 提示注入（文档正文含恶意指令） | 模型被诱导 | 系统提示隔离、输入输出过滤、引用约束 |
